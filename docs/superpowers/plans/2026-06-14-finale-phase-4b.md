# Finale — Light Touch (Phase 4b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the loop grammar with the lightest possible touch — a subtle hover polish on the index care-orbits, and the three prose essays' chapter-dividers becoming the loop's orbit-ring — **without** imposing the orrery on the essays' bespoke heroes (which would homogenize the "plurality of registers" the design rests on).

**Architecture:** (1) **Care hover polish** — on `.work-grid > .work-item:hover`, the orbit ring (`::before`) brightens and grows slightly; nothing is hidden, so the no-JS/a11y baseline is untouched (the descriptions are always shown). Appends to `src/styles/orrery.css`. (2) **Essay divider orbit-ring** — the identical `.divider-mark` rule in the three prose essays changes from a rotated square to a small ring + rim node, joining the loop grammar through an element the essays already have. No essay hero, no per-essay HTML, no new files. **No JS, no new CSP hashes** (the hover polish is a one-shot transition, not a continuous animation, and needs one explicit `prefers-reduced-motion` rule on the `::before`, taking the reduced-motion block count 4 → 5).

**Tech Stack:** Bun (`weave.ts` + `pre-commit.ts`), hand-authored HTML/CSS, no framework.

**Source of truth:** Phase 4b of `docs/superpowers/specs/2026-06-14-in-the-loop-of-humanity-design.md` (§5g), scoped per the user's **"light touch"** decision. **Depends on Phases 1–4a** (`src/styles/orrery.css`, the care-orbits, `--orrery-line`/`--orrery-bright`).

**Three deliberate divergences from the spec, decided with the user:**
1. **No orrery on essay heroes.** Spec §5g 4b says replicate the orrery onto each essay hero. Each essay carries its *own* bespoke hero motif (transparent-horse a `.hero-crystal`; collaborative-immune-system and good-enough-ancestor a `.hero-emblem`; each its own year) — imposing one instrument would flatten the plurality of registers the design depends on. The essays keep their heroes; only the small grammar (the chapter-divider mark) joins the loop.
2. **Care "expansion" is a hover *polish*, not a content reveal.** Spec §5g 4b says hover/focus-*expand* to reveal the principle. The care work-items already show their full descriptions, so there is nothing to reveal without first *hiding* it (which would break the no-JS/a11y baseline). Instead, hover brightens/grows the decorative orbit ring — no content gated. `:hover` only (the work-item is a non-focusable `<div>`; nothing is hidden, so keyboard/touch users miss only a decorative flourish, never information).
3. **Essay touch via the existing `.divider-mark`, not a new element.** `essay.css` is inlined *before* the per-essay styles (sentinels at ~line 21–154; `.divider-mark` at ~line 419), so it cannot override them — the change is a direct per-essay edit. The rule is byte-identical across the three prose essays, so it is one find/replace applied to three files. pi-ds4 has no `.divider-mark` and is untouched.

## Task 1: Care-orbit hover polish (index)

**Files:** Modify `src/styles/orrery.css` (append).

- [ ] **Step 1: Append** to the end of `src/styles/orrery.css`

```css

/* ─── Finale: care-orbit hover polish (Phase 4b) ──────────────────────── */
/* On hover the bounded orbit's ring brightens and grows a touch — the kami
   stirs. Decorative only: nothing is hidden, the descriptions are always
   shown, and the global reduced-motion rule snaps the transition off. */
.work-grid > .work-item::before {
  transition: opacity .3s ease, border-color .3s ease, transform .4s cubic-bezier(.22, 1, .36, 1);
}
.work-grid > .work-item:hover::before {
  opacity: 1; border-color: var(--orrery-bright); transform: scale(1.15);
}
@media (prefers-reduced-motion: reduce) { .work-grid > .work-item::before { transition: none; } }
```
> The `::before` ring is `position: absolute`, so `transform: scale()` changes nothing in flow (no layout shift). `--orrery-bright` is the scheme-invariant bright gold. **Reduced-motion needs its own pseudo-element rule:** the global `* { transition: none !important }` (components.css ~1074) does **not** match pseudo-elements, so the explicit `@media (prefers-reduced-motion: reduce) { …::before { transition: none } }` above is what snaps the hover off (mirroring the Phase-3 `::after` precedent at orrery.css:125). This adds **one** new reduced-motion block, so the woven count becomes **5**.

- [ ] **Step 2: Sanity-check**

Run:
```bash

```
Expected: `1`.

- [ ] **Step 3: Commit**

